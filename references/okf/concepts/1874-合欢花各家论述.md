# 合欢花各家论述

《本草便读》能养血；《分类草药性》能清心明目；《四川中药志》能合心志、开胃理气、消风明目、解郁，治心虚失眠；江西《中草药学》解郁安神、和络止痛，治肝郁胸闷、忧而不乐、健忘失眠；《东北常用中草药手册》治咽喉疼痛。
