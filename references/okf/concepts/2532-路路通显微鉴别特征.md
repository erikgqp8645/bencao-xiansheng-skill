# 路路通显微鉴别特征

路路通粉末显微特征：纤维多断碎，壁多波状弯曲，木化；果皮石细胞类方形、梭形或不规则形，壁极厚；宿萼表皮细胞多角形，壁厚，具孔沟；单细胞毛常弯曲，含棕黄色物。
