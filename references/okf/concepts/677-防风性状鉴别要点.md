# 防风性状鉴别要点

防风根呈圆锥形或纺锤形，表面灰黄色或灰棕色，根头部有密集细环节（蚯蚓头），节上有棕色粗毛（扫帚头），断面木部淡黄色、皮部黄棕色有裂隙，射线放射状（菊花心），质松软，气微香，味微甘。
