# 七情

药有七情：单行、相须、相使、相恶、相畏、相反、相杀。单行独能攻补，相须二药相宜，相使引达诸经，相恶彼有毒而我恶之，相畏我有能而彼畏之，相反两相仇隙，相杀中彼药毒用此杀除。
