# 蜡梅花化学成份

香气成分已鉴定31种，含量最多的是罗勒烯，其次是芳樟醇、乙酸苄酯、水杨酸甲酯等；另含红豆杉氰甙、蜡梅甙、α-胡萝卜素、蜡梅碱等。
