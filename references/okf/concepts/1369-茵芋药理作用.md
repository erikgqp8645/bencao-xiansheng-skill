# 茵芋药理作用

茵芋碱有麻黄碱样作用，可升高麻醉猫血压，增强瞬膜收缩，加强肾上腺素对血压及子宫的作用，加强猫或兔的在位子宫收缩，抑制小肠收缩及扩张冠状血管等。此外，还能提高横纹肌张力，加强脊髓反射兴奋性。
