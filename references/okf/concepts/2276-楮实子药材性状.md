# 楮实子药材性状

楮实子为桑科植物构树的果实，呈扁圆形或扁卵形，长约2mm，表面橙红色或棕红色，有微细网状纹理，一侧有凹沟，另一侧有棱线，质硬，内含种子1粒，种皮红棕色，种仁白色油质，味淡。
