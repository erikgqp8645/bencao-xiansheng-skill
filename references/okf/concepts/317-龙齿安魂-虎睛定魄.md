# 龙齿安魂、虎睛定魄

东方苍龙属木，属肝藏魂；西方白虎属金，属肺藏魄。龙能变化故魂游不定，虎能专静故魄止能守。魄不宁者宜治以虎睛，魂飞扬者宜治以龙齿。
