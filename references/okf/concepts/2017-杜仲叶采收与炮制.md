# 杜仲叶采收与炮制

秋末采收，除去杂质，洗净，晒干。炮制方法有：杜仲叶（除去杂质，切丝，筛去灰屑）和盐炒杜仲叶（用盐水喷匀，稍闷，炒至有焦斑，每100kg用食盐2kg）。
