# 虎杖性味归经与功效

虎杖性味微苦、微寒，归肝、胆、肺经，功效为清热解毒、利胆退黄、祛风利湿、散瘀定痛、止咳化痰，用于关节痹痛、湿热黄疸、经闭、癥瘕、咳嗽痰多、水火烫伤、跌扑损伤、痈肿疮毒。
