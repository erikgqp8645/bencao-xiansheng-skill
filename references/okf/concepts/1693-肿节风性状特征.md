# 肿节风性状特征

药材长50-120cm，根茎粗大，茎圆柱形有纵纹和皮孔，节膨大，质脆易折断，断面有髓或中空。叶对生，卵状披针形，边缘有粗锯齿，齿尖腺体黑褐色，近革质。气微香，味微辛。
