# 白矾的基原与性状

白矾为硫酸盐类矿物明矾石经加工提炼而成的结晶，主含含水硫酸铝钾。性状为不规则块状或粒状，无色或淡黄白色，透明或半透明，具玻璃样光泽，质硬而脆，味酸、微甘而极涩。
