# 刺五加化学成分

根含刺五加甙A、B、B1、C、D、E，刺五加甙A即是胡萝卜甙，刺五加甙B即是丁香甙；根还含芥子醛葡萄糖甙，松柏醛葡萄糖甙，松柏甙，鹅掌楸甙，苦杏仁甙等。
