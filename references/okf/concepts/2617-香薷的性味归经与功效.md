# 香薷的性味归经与功效

香薷味辛，性微温，归肺、胃经。功效为发汗解表，和中利湿，行水消肿。主治夏月外感风寒、内伤于湿所致的恶寒发热、头痛无汗、脘腹疼痛、呕吐腹泻、小便不利、水肿等。
