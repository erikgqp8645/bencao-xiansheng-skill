# 黄精的三种商品规格

按形状不同，黄精习称“大黄精”、“鸡头黄精”、“姜形黄精”。大黄精呈肥厚肉质的结节块状；鸡头黄精呈结节状弯柱形；姜形黄精呈长条结节块状，常数个块状结节相连。
