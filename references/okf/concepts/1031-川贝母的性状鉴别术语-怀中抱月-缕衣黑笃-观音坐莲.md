# 川贝母的性状鉴别术语：怀中抱月、缕衣黑笃、观音坐莲

松贝的鉴别术语：怀中抱月指外层鳞叶2瓣大小悬殊，大瓣紧抱小瓣，未抱部分呈新月形；缕衣黑笃指基部稍凹入，间见黑斑，留有根须痕；观音坐莲指底部平、微凹入，平放能端正稳坐。
