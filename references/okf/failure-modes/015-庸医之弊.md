# 庸医之弊

今庸医处治，皆耻看本草，或倚约旧方，或闻人传说，或遇其所忆，便揽笔疏之，俄然戴面，以此表奇。其畏恶相反，故自寡昧，而药类违僻，分两参差，亦不以为疑脱。偶而值瘥，则自信方验；若旬月未瘳，则言病源深结，了不反求诸已。
