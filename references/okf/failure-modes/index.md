# Failure Modes

- [庸医之弊](001-庸医之弊.md) - 庸医处疗，皆耻看本草，或倚约旧方，或闻人传说，或遇其所忆，便揽笔疏之。其畏恶相反，故自寡昧，而药类违僻，分两参差，亦不以为疑脱。
- [本药杂别种则不能取效](002-本药杂别种则不能取效.md) - 本药中夹杂其他种类，使用则不能取效，甚至有害，如柴胡中夹杂白头翁、小前胡等。
- [药物误用风险警示](003-药物误用风险警示.md) - 误用伪品或炮制不当可致严重后果，如误服冷油石令人腰以下不能举，不炼服礜石杀人，服用水银粉虚人不宜服。
- [滑石误用冷油石之害](004-滑石误用冷油石之害.md) - 冷油石与凝水石相类，但投沸油铛中油即冷者，此石有毒，若误用之，令腰以下不能举。
- [远志误用致心痛](005-远志误用致心痛.md) - 指出远志无补性，纯虚无滞者误服会导致空洞悬心痛，且心经有实火者禁与参术同用。
- [麦冬闭肺窍致失音](006-麦冬闭肺窍致失音.md) - 引述徐洄溪观点，指出麦冬能闭肺窍导致失音，湿痰咳嗽者用之会使湿热壅滞，肺失清肃。
- [生熟地黄的禁忌](007-生熟地黄的禁忌.md) - 生地黄性寒而润，胃虚食少、脾虚泻多者禁服。熟地黄性滞，痰多气郁之人能窒碍胸膈，需斟酌使用。用姜酒拌炒后，生者不妨胃，熟者不泥膈。
- [唐容川释桂枝诸方自相矛盾](008-唐容川释桂枝诸方自相矛盾.md) - 唐容川对桂枝在不同方剂中的归经与作用解释纷然淆乱，如既言桂枝为心药肝药，又言其入膀胱化气，茫无真见。
- [误用黄柏知母之害](009-误用黄柏知母之害.md) - 虚损之人若以知母黄柏为君，日日服饵，会导致脾胃受伤、真阳暗损。
- [四神丸治肾泻不效之因](010-四神丸治肾泻不效之因.md) - 肾虚作泻若因饮酒过多加色欲，致酒湿入肾，而非命门寒，用四神丸（含肉豆蔻）反增后重之症。
- [水银轻粉中毒症状及解救](011-水银轻粉中毒症状及解救.md) - 凡服食水银轻粉，虽易收效，然毒窜经络，或口齿肿烂，或筋骨疼痛挛缩，久则溃烂难愈，致成废疾。治服食中毒溃烂者，内服红枣丸，外敷虾蟆散。
- [服杏丹之妄诞](012-服杏丹之妄诞.md) - 古有服杏丹法，云是左慈之方。唐慎微收入本草，云久服寿至千万。其说妄诞可鄙，今删其纰谬之辞。
- [胡椒久服之弊](013-胡椒久服之弊.md) - 李时珍自少嗜胡椒，岁岁病目而不疑，后渐知其弊，遂痛绝之，目病亦止。才食一二粒，即便昏涩。胡椒大辛热，纯阳之物，肠胃寒湿者宜之，热病者食之动火伤气。
- [误服白蝙蝠致死案例](014-误服白蝙蝠致死案例.md) - 李时珍引唐陈子真、宋刘亮服白蝙蝠后大泄或立死之例，驳斥《仙经》所谓服之不死之说，指出蝙蝠性泻人，治病可，服食不可。
- [庸医之弊](015-庸医之弊.md) - 今庸医处治，皆耻看本草，或倚约旧方，或闻人传说，或遇其所忆，便揽笔疏之，俄然戴面，以此表奇。其畏恶相反，故自寡昧，而药类违僻，分两参差，亦不以为疑脱。偶而值瘥，则自信方验；若旬月未瘳，则言病源深结，了不反求诸已。
- [误用柴胡之戒](016-误用柴胡之戒.md) - 《本经》未言柴胡治劳，后世治劳方中滥用，若无实热而用，可致人死，注释本草不可忽。
- [误用白术治疳：愈燥而愈剧](017-误用白术治疳-愈燥而愈剧.md) - 疳证不可概用白术等燥湿之品。疳证由于脾阴先亏，若以白术燥之，则愈燥而愈剧。此与脾气下陷而术能健之生津益液者不同。
- [威灵仙禁忌：风药性升而燥之戒](018-威灵仙禁忌-风药性升而燥之戒.md) - 希雍指出风药性升而燥，走而不守，凡病非风湿及阳盛火升、血虚有热、表虚有汗、痲症口渴身热者，并忌用之。
- [人参误用之戒](019-人参误用之戒.md) - 人参长于补虚而短于攻疾，病未去而用参，则病根遂固，诸药罔效，终无愈期，故曰杀人者多也。
- [熟地胶粘护邪害](020-熟地胶粘护邪害.md) - 熟地胶粘善着，能护胎亦能护邪，误用则引邪敛存少阴，百药不效。
- [神曲误服之害](021-神曲误服之害.md) - 陈修园痛斥神曲杂药乱制，误服伤元气，泉州一带先救误服神曲之害者十居其七。
- [六失致难治](022-六失致难治.md) - 不可治者有六失：失于不审、不信、过时、不择医、不识病、不知药，有一即为难治。
- [商陆赤白品种误用风险](023-商陆赤白品种误用风险.md) - 商陆有赤白二种，白者入药用，赤者见鬼神甚有毒，但贴肿处用。若服之伤人，乃至痢血不已而死。又一种名赤菖，苗叶绝相类，不可用，服之伤筋消肾，须细辨之。
- [雄黄的伪品与误用风险](024-雄黄的伪品与误用风险.md) - 列举了雄黄的伪品（黑鸡黄、自死黄、夹腻黄），并指出其有臭味，不可误用。
- [干地黄禁忌](025-干地黄禁忌.md) - 强调炮制干地黄时勿犯铜铁器，否则会导致肾消、髭发白等严重后果。
- [虚劳家丸散用之未允](026-虚劳家丸散用之未允.md) - 虚劳家丸散用云母只捣筛不精制，殊为未允。
- [伪玉的辨识](027-伪玉的辨识.md) - 仪州栗玉乃黄石之光莹者，轻小，刀刃便可雕刻，与阶州白石同体而异色，恐不足继诸玉类。
- [钟乳石误用致祸](028-钟乳石误用致祸.md) - 昧者服钟乳后阳气暴充，肆淫，精气暗损，石气独存，孤阳愈炽，久之营卫不从，发为淋浊痈疽。
- [硝石性寒之误](029-硝石性寒之误.md) - 李时珍指出《本经》《别录》言硝石性寒为误。凡辛苦物未有大寒者，硝石得火则焰生，与樟脑、火酒性同，应为辛苦微咸而大温。
- [石胆伪品及误用警示](030-石胆伪品及误用警示.md) - 市人多以醋揉青矾伪之，或以绛矾为石胆，或以粗恶石胆合硝石销溜而成，均属伪品。俗用青色矾石当之，殊无仿佛。
- [误用禹余粮救荒之弊](031-误用禹余粮救荒之弊.md) - 以禹余粮充饥不可行，饥馑之民肠胃虚弱，用重物充饥反速其死。
- [误用人参的两种常见情形](032-误用人参的两种常见情形.md) - 《得配本草》指出用参之误有二：一是阴虚火炎者误用，以为补气可生阴，实则助火；二是外感邪气内伏，脉象虚微被误认为脱症而用人参，导致邪气内着，火毒郁里。
- [误用熟地黄致邪气敛藏](033-误用熟地黄致邪气敛藏.md) - 陈修园指出熟地黄胶粘善着，如油入面，一着遂不能去；凡遇有邪而误用此药者，百药不效。
- [茺蔚子中毒反应](034-茺蔚子中毒反应.md) - 一次服食茺蔚子30克以上可引起中毒，4-6小时后出现胸闷无力，全身酸痛，下肢不能活动等症状。
- [误用野狼毒之谬](035-误用野狼毒之谬.md) - 当时有用枯朽野狼毒充当防葵的情况，极为谬误。
- [误用柴胡之弊](036-误用柴胡之弊.md) - 今人治疟必用柴胡，若非柴胡即不足以为治者，故致辗转淹滞，变生不测，竟能殒阳正气。
- [车前子催生不可单用](037-车前子催生不可单用.md) - 车前子性滑自易于生产，然不可单藉。必须于补气、补血之中，佐车前子之滑利，庶几催生有验。若只图车前之滑胞，恐过利其水，胎胞干燥，转难生产。
- [误认蒺藜为补剂的用药失误](038-误认蒺藜为补剂的用药失误.md) - 白蒺藜虽载温能补肾，然总宣散肝经风邪，若竟认此作补，而不审兼苦泄辛散以明其治，其失靡轻。
- [误用蒲黄干姜之弊](039-误用蒲黄干姜之弊.md) - 舌根胀痛，亦有属阴虚火旺者，误用蒲黄干姜法，转伤津液，每致燥涩愈甚，不可不审。
- [茜草伪品赤柳草根](040-茜草伪品赤柳草根.md) - 赤柳草根真似茜根，只是味酸涩，不入药中用。若服，令人患内障眼，速服甘草水解之。
- [雷公炮炙论：勿用鸭喋草根](041-雷公炮炙论-勿用鸭喋草根.md) - 雷公指出鸭喋草根与杜若真相似，但味效不同，不可混用。
- [初病太阳证误用升麻之害](042-初病太阳证误用升麻之害.md) - 若初病太阳证便服升麻、葛根，发出阳明经汗，或失之过，阳明经燥，太阳经不可解，必传阳明。投汤不当，非徒无益，而又害之。
- [胡麻油久存之弊](043-胡麻油久存之弊.md) - 熬熟油须逐日熬用，经宿则火性反复，能助热动气。
- [辛夷使用禁忌](044-辛夷使用禁忌.md) - 辛夷辛香走窜，气虚人忌，头脑痛属血虚火炽者忌，齿痛属胃火者忌。毛射入肺令人咳，需去毛。
- [以人补人之说之害](045-以人补人之说之害.md) - 后人惑于以人补人之说，每用紫河车增热为害，十服十死，不如用发髲之验。
- [方家误用天灵盖](046-方家误用天灵盖.md) - 方家至用天灵盖，害及枯骨，卒不能治病，古人所无。
- [桑螵蛸误用禁忌：阴虚多火者禁用](047-桑螵蛸误用禁忌-阴虚多火者禁用.md) - 阴虚多火人误用反助虚阳，多致溲赤、茎痛、强中失精。凡失精遗溺火气太盛者宜少少用之。
- [游波虫骨的鉴别与误食后果](048-游波虫骨的鉴别与误食后果.md) - 游波虫骨似海蛤但面上无光，误食令人狂眩，用醋蜜解之即愈。
- [伪品海蛤的鉴别](049-伪品海蛤的鉴别.md) - 海人多以它蛤壳经风涛摩荡莹滑者伪作海蛤，殊无力。
- [蒸不熟令人发落](050-蒸不熟令人发落.md) - 胡麻蒸不熟会令人发落。
- [误用硫黄之害](051-误用硫黄之害.md) - 火极似水，症见寒厥，不细审认，辄作寒治，遽用此药，其害匪浅。
- [苦参揩齿致腰重](052-苦参揩齿致腰重.md) - 久用苦参揩齿，其气味入齿伤肾，可致腰重。有朝士病腰重，因用苦参揩齿数年所致，后停用苦参，腰疾皆愈。
- [蠡实避孕效果不理想](053-蠡实避孕效果不理想.md) - 马蔺子作避孕药效果欠理想，汤剂和胶囊均有较高怀孕率，且少数有月经提前、错后、经量异常、白带增多等副作用。
- [误用知母滋阴之弊](054-误用知母滋阴之弊.md) - 后世误将知母作滋阴上剂，用于虚损之人，如水益深，致夭枉者多。
- [石灰炮制白芷的弊端](055-石灰炮制白芷的弊端.md) - 近时用锻石蒸煮或拌锻石曝晒，虽不易蛀且色白，但不特失其本性，而燥烈之毒最深，用时不可忽视。
- [《本草正义》警示误用仙灵脾酒](056-本草正义-警示误用仙灵脾酒.md) - 仙灵脾酒止可治风寒湿痹之不遂，并不能治气血两虚之不遂，而血冲脑经之不遂（中风）更万万不可误用。
- [苏恭对陶隐居鉴别法的批评](057-苏恭对陶隐居鉴别法的批评.md) - 苏恭认为陶隐居以子细者为真并非通论，因产地不同子粒大小有异，山南者粒大如葵子，关中河北者细如葶苈，气力劣于山南者。
- [防己误用三害](058-防己误用三害.md) - 虚人用防己其害有三：一、谷食己亏，复泄大便，重亡其血；二、渴在上焦气分，而防己泻下焦血分；三、伤寒邪传肺经气分，湿热而小便黄赤，禁用血药。
- [吴茱萸误用风险：姜附错用伤元气](059-吴茱萸误用风险-姜附错用伤元气.md) - 少阴之躁与厥阴之躁病机不同，吴茱萸与姜附虽皆大热，但主治不同，错用反伤元气，元阳消散则难救。
- [猪苓误用之害](060-猪苓误用之害.md) - 猪苓专司引水，津液易耗，多用能亡津液，久服必损肾气、昏人目；若无湿证而用之，则重亡津液，阴愈虚，甚则小便点滴不出。
- [松萝酸钠副作用](061-松萝酸钠副作用.md) - 松萝酸钠用药过程中约20%患者有胃部不适，个别胃痛，部分出现视力不佳，可用健胃药及鱼肝油解除。
- [白马茎炮制失败模式](062-白马茎炮制失败模式.md) - 老死取者不效；悬壁阴干，务周百日；用铜刀劈七片，拌羊血蒸三时；晒燥以粗布净揩（揩去上皮及干羊血）。
- [露蜂房使用禁忌](063-露蜂房使用禁忌.md) - 凡病属气血虚无外邪者，与痈疽溃后元气乏绝者，均忌服。气血虚弱者慎服，肾功能不全者慎服。贼风感者用之无效。
- [市售白僵蚕伪劣风险](064-市售白僵蚕伪劣风险.md) - 市售有用中温死蚕以石灰淹拌令白者，服之为害最深，痘疹用之可致燥裂黑陷。
- [误用蟅虫之祸](065-误用蟅虫之祸.md) - 雷公炮制药性解指出，跌打损伤者若无论有无瘀血均用蟅虫，甚至无效加重，是愚者不察。有瘀血作疼者方为要药；无瘀血而伤在筋骨脏腑之间，法当和补。
- [铅丹误服中毒表现](066-铅丹误服中毒表现.md) - 误服铅丹可致四肢冰冷强直、食不入口等严重中毒反应，需急用附子理中汤救治。
- [卤碱静脉注射的不良反应](067-卤碱静脉注射的不良反应.md) - 静脉注射偶可发生过敏反应如荨麻疹、发烧；少数沿注射血管疼痛；个别体弱、空腹或月经期注射后出现颜面苍白、出冷汗甚至呕吐。注射过快或浓度过高可致中毒。
- [莨菪子误用风险](068-莨菪子误用风险.md) - 莨菪子有大毒，误服或过服可致中毒，表现为冲人心大烦闷、眼生星火；多食令人狂走。
- [藜芦误用危害：大损津液](069-藜芦误用危害-大损津液.md) - 藜芦非实邪壅滞者慎勿轻试，不可因《本经》之言而致惑。服一匕则令人胸中烦闷，吐逆不止，大损胃中津液。
- [射干使用注意](070-射干使用注意.md) - 射干有泻无补，能通利大肠，服之必泻。无益阴之性，久服令人虚。多服泻人。
