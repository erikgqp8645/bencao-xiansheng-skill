# 马钱子中毒表现与解救

马钱子中毒出现颈项僵硬，瞳孔散大，呼吸急促与困难，甚至抽搐，角弓反张，痉笑等症状。解救方法包括乙醚吸入麻醉、巴比妥类药物制止惊厥、高锰酸钾洗胃、置暗室防止刺激。禁用吗啡。
