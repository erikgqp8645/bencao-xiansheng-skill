# 番泻叶伪品耳叶番泻鉴别

进口番泻叶中常夹杂耳叶番泻叶，呈卵圆形或倒卵形，先端钝圆或微凹，或具刺突，基部对称或不对称，表面黄灰绿色至红棕色，被有灰白色毛茸，有的极多，掺杂量有时高达60%，其蒽醌衍生物含量极微。
