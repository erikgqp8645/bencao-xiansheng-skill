# 金樱子显微鉴别特征

花托壁横切面：外表皮细胞类方形或略径向延长，外壁及侧壁增厚，角质化；皮层薄壁细胞含油滴及橙黄色物，有的含草酸钙方晶及簇晶；纤维束散列于近皮层外侧；维管束外韧型。粉末：非腺毛长505-1836μm，壁木化，表面有斜条纹；草酸钙方晶多见，直径16-39μm；簇晶少见，直径27-66μm；导管直径8-20μm；纤维黄色，长至1071μm。
