# 黄连品质鉴别要点

黄连以节多坚重、相击有声、色鲜明如赤金者善。芦多者劣，瘦小须多者不堪入药。雅州连细长弯曲微黄无毛有硬刺、马湖连色黑细毛绣花针头硬刺形如鸡爪为最佳。
