# 木通药材性状鉴别

木通藤茎圆柱形，稍扭曲，表面灰棕色，有光泽，有浅纵纹，皮孔突起；质坚脆，较易折断，断面木部灰白色，导管孔排列紧密而无规则，中央髓圆形明显。
