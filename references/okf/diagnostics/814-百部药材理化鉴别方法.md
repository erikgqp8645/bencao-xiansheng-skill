# 百部药材理化鉴别方法

取本品粉末5g，加70%乙醇50ml，加热回流1小时，滤过，滤液蒸去乙醇，残渣加浓氨试液调节pH值至10～11，再加氯仿5ml振摇提取，分取氯仿层，蒸干，残渣加1%盐酸溶液5ml使溶解，滤过。滤液分作两份：一份中滴加碘化铋钾试液，生成橙红色沉淀；另一份中滴加硅钨酸试液，生成乳白色沉淀。
