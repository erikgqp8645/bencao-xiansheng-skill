# 槲寄生显微鉴别特征

茎横切面：表皮细胞长方形，外被黄绿色角质层厚19-80μm；皮层宽广，纤维成束微木化，老茎石细胞多；韧皮部窄，老茎散有石细胞；形成层不明显；木质部射线散有纤维束，导管周围纤维多，有异形细胞；髓明显；薄壁细胞含草酸钙簇晶(17-45μm)及少数方晶(8-30μm)。粉末淡黄色，纤维直径10-34μm壁厚略波状微木化，石细胞直径42-102μm。
