# 牡丹皮性状鉴别要点

牡丹皮呈筒状或半筒状，外表面灰褐色或黄褐色，有横长皮孔，栓皮脱落处粉红色；内表面有细纵纹，常见发亮的牡丹酚结晶；质硬而脆，断面淡粉红色、粉性。
