# 豆蔻类药材的鉴别要点

鉴别豆蔻类药材时，需注意观察其形状、表面颜色、隔膜、种子形态、种脊、气味等性状特征，如草豆蔻种子团类球形、白豆蔻果实圆球形、红豆蔻果实长圆形、肉豆蔻卵圆形且断面有大理石花纹。
