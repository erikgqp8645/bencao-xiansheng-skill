# 茜根治血证：滞血发热之明验

前哲论滞血发热者，其脉涩，外证必兼嗽，水必兼呕恶痰涎，或病或两脚厥冷，或病小腹结急，或唾血，或鼻衄，皆滞血发热之明验；热毒瘀血在小便为淋痛，在大便为肠风。
