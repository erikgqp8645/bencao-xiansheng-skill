# 桑枝性状鉴别要点

桑枝呈长圆柱形，表面灰黄色或黄褐色，有多数黄褐色点状皮孔及细纵纹，并有灰白色略呈半圆形的叶痕和黄棕色腋芽。质坚韧，不易折断，断面纤维性。以质嫩、断面黄白色者为佳。
