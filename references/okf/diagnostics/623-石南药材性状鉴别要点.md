# 石南药材性状鉴别要点

茎圆柱形，表面暗灰棕色，有纵皱纹，皮孔细点状；叶互生，叶片长椭圆形或倒卵状椭圆形，边缘具细密锯齿，齿端棕色，幼时及萌发枝上的叶缘具芒状锯齿；叶片革质而脆。以枝嫩、条匀、叶完整无碎者为佳。
