# 现代人读不懂《伤寒论》的原因

现代人读不懂《伤寒论》的原因有二：一是失去了中医的根本（道），医生不再修道而津津于“术”；二是不懂书，不读《本经疏证》这类剖析《伤寒论》的著作。
