# 毛慈菇与冰球子横切面鉴别

毛慈菇横切面最外层为扁平表皮细胞，内有2～3列厚壁细胞，再向内为大的类圆形薄壁细胞含黏液质及淀粉粒，近表皮处薄壁细胞含草酸钙针晶束。冰球子表皮细胞切向延长，淀粉粒存在于较小薄壁细胞中，维管束鞘纤维半月形。
