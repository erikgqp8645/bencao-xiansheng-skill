# 海螵蛸与桑螵蛸鉴别

海螵蛸具有止血、制酸特长，也能固精止带，但无补益作用；桑螵蛸以固精缩尿为特长，具有益肾功效。乌贼骨功专收涩，多服久服可引起大便秘结。
