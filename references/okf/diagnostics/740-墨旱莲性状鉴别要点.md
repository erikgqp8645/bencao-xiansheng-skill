# 墨旱莲性状鉴别要点

墨旱莲全体被白色茸毛，茎圆柱形有纵棱，表面绿褐色或墨绿色，叶对生近无柄，叶片皱缩卷曲或破碎，头状花序直径2-6mm，瘦果椭圆形而扁，气微味微咸。
