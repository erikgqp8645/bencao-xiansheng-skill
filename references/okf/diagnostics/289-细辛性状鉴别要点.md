# 细辛性状鉴别要点

北细辛：根茎横生呈不规则圆柱形，表面灰棕色，粗糙，具环形节，根细长密生节上，质脆易断，断面黄白色，气辛香，味辛辣、麻舌。华细辛：根茎较长，叶片较薄，心形，先端渐尖，气味较弱。汉城细辛：根茎直径0.1-0.5cm，节间长0.1-1cm，气味同北细辛。
