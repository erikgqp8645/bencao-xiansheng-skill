# 牡荆叶理化鉴别

取本品粉末1g，用石油醚脱脂，滤过，残渣加乙醇10ml，浸泡过夜，滤过。滤液浓缩至1ml。于2支试管中各加浓缩液2滴，再分别加入盐酸-镁粉、盐酸-锌粉试剂，依次显现橙黄色和樱红色。（检查黄酮）
