# 紫花地丁显微鉴别要点

叶横切面：上表皮细胞较大，切向延长，外壁较厚，内壁黏液化；下表皮细胞较小，偶有黏液细胞；上下表皮有单细胞非腺毛；栅栏细胞2-3列；海绵细胞含草酸钙簇晶。根横切面：最外层为4-6层木栓细胞；韧皮部宽广；形成层环状；木质部导管散列或成群；薄壁细胞含淀粉粒与草酸钙簇晶。
