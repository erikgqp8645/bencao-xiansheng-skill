# 龙胆草性状鉴别要点

龙胆根茎呈不规则块状，表面暗灰棕色或深棕色，上端有茎痕或残留茎基；根圆柱形略扭曲，表面淡黄色或黄棕色，上部多有显著横皱纹，下部较细有纵皱纹及支根痕；质脆易折断，断面皮部黄白色或淡黄棕色，木部色较浅呈点状环列；气微，味甚苦。
