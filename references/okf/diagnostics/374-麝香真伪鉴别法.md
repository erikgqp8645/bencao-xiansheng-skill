# 麝香真伪鉴别法

取香剂中当门子，捻之如血线，拓之如桃花瓣，燥甚者始真。然多伪造，虽膜囊完固弗信，但破看一片，毛在其裹中者为胜。市人或插荔枝核以伪之。
