# 眼病虚实与部位辨证

淡紫而隐红为虚热，鲜红而妒赤为实热；两眦生胬肉为心热血旺，白睛红膜如伞纸为气滞血凝；白睛带赤或红筋热在肺，胞睑如疮点热属脾。
