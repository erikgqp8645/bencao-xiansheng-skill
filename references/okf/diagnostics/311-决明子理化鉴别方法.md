# 决明子理化鉴别方法

决明子鉴别：取粉末加稀硫酸和氯仿回流，碱液层显红色；或取粉末甲醇提取后水解，以大黄素、大黄酚对照品进行薄层色谱，紫外灯下显橙色荧光，氨熏后变红。
