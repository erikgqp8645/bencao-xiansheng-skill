# 大豆黄卷性状鉴别要点

干燥种子呈椭圆形稍扁，种皮黑褐色或紫褐色，有横向皱纹或纵裂，多数破裂露出黄白色子叶，胚根细长伸出种皮之外，极弯，淡褐色，硬脆易断。以粒大饱满、色黑褐、有皱纹及短芽者为佳。
