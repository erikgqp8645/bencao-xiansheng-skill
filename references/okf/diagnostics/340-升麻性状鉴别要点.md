# 升麻性状鉴别要点

升麻呈不规则长形块状，多分枝，结节状，表面黑褐色或棕褐色，有圆形空洞的茎基痕，洞内壁显放射状网纹，断面纤维性，黄绿色或淡黄白色，气微，味微苦而涩。
