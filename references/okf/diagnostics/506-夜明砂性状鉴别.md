# 夜明砂性状鉴别

夜明砂为长椭圆形颗粒，两端微尖，长5-7毫米，直径约2毫米，表面粗糙，棕褐色或灰棕色，放大镜下可见棕色或黄棕色有光泽的昆虫头、眼及小翅，气无，味微苦而辛。以身干无砂土、色棕褐、质轻、嚼之无砂感、并有小壳点者为佳。
