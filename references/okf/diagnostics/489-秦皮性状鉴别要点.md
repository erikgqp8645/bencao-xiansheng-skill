# 秦皮性状鉴别要点

枝皮呈卷筒状或槽状，外表面灰白色、灰棕色至黑棕色或相间呈斑状，有灰白色圆点状皮孔及细斜皱纹；内表面黄白色或棕色，平滑；质硬而脆，断面纤维性，黄白色；无臭，味苦。
