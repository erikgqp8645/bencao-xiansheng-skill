# 土茯苓辨真伪：川蓟与菝葜根鉴别

王文洁指出，川蓟（土茯苓）形体壮大突兀，切开白莹带粉；而菝葜根色红、形相似但味苦涩，常被贩者冒充川蓟，用者需辨别。
