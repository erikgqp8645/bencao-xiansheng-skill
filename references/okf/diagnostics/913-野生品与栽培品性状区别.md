# 野生品与栽培品性状区别

野生品：有沙眼，断面较疏松有裂隙，木部放射状纹理明显。栽培品：有分枝，下部多扭曲，纵皱纹细腻明显，细支根痕多呈点状凹陷，几无沙眼，断面较紧密，几无裂隙，略显粉性，木部放射状纹理不甚明显，味微甜。
