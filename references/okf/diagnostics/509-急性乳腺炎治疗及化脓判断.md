# 急性乳腺炎治疗及化脓判断

露蜂房文火焙焦研末，温黄酒冲服，每4小时1次，3天一疗程。若已有化脓倾向者本法无效，应考虑手术治疗。病程10天以下者大都可消散痊愈。
