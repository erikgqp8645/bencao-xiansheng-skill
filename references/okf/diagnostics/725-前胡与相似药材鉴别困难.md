# 前胡与相似药材鉴别困难

当归与独活、前胡极为相似，外观鉴别网上辨别方法少且混杂，部分说辞略有矛盾，难以信服。防风、升麻、当归、前胡、独活、白芷外形相似，虽附有辨别方法，但辨别仍有难度，需在专业老师指导下分辨。
