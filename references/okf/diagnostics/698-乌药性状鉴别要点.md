# 乌药性状鉴别要点

乌药性状鉴别要点：纺锤状，略弯曲，有的中部收缩成连珠状，表面黄棕色或黄褐色，有纵皱纹及稀疏细根痕，质坚硬，切面黄白色或淡黄棕色，射线放射状，可见年轮环纹，中心颜色较深，气香，味微苦、辛，有清凉感。
