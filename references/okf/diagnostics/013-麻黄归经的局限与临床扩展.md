# 麻黄归经的局限与临床扩展

麻黄归经为肺与膀胱经，但此归类限制了其功用。现代中医仅知其发汗散寒、宣肺平喘、利水消肿，但临床上它还可起到健脾作用，因麻黄色黄入脾。
