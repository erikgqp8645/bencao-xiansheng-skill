# 皂角刺性状鉴别要点

主刺长3-15cm或更长，分枝刺长1-6cm，表面紫棕色或棕褐色，质坚硬不易折断，切片木部黄白色，髓部淡红棕色疏松，质脆易折断，气微味淡。
