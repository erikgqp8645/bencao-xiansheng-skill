# 连翘性状鉴别要点

连翘果实呈长卵形至卵形，表面有不规则纵皱纹及凸起小斑点，两面各有1条明显纵沟。青翘多不开裂，表面绿褐色，质硬，种子多数黄绿色；老翘自顶端开裂或裂成两瓣，表面黄棕色或红棕色，内表面浅黄棕色平滑具一纵隔，质脆，种子多脱落。
