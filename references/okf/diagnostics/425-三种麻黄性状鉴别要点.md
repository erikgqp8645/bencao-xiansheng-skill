# 三种麻黄性状鉴别要点

草麻黄：少分枝，直径1-2mm，有粗糙感，节间长2-6cm，鳞叶裂片2（稀3），先端反曲，断面髓部近圆形。木贼麻黄：多分枝，直径1-1.5mm，无粗糙感，节间长1.5-3cm，鳞叶裂片2（稀3），先端多不反曲，基部棕红色至棕黑色。中麻黄：多分枝，直径1.5-3mm，有粗糙感，节间长2-6cm，鳞叶裂片3（稀2），先端锐尖，断面髓部三角状圆形。
