# 九里香与千里香性状鉴别要点

九里香小叶片呈倒卵形或近菱形，最宽处在中部以上，先端钝、急尖或凹入；千里香小叶片呈卵形或椭圆形，最宽处在中部或中部以下，先端渐尖或短尖。
