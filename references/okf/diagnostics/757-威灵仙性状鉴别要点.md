# 威灵仙性状鉴别要点

威灵仙根茎呈柱状，表面淡棕黄色，断面纤维性；根细长圆柱形，表面黑褐色，有细纵纹，断面木部淡黄色略呈方形，皮部与木部间常有裂隙。
