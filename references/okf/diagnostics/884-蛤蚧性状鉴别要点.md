# 蛤蚧性状鉴别要点

蛤蚧呈扁片状，头颈部及躯干部长9-18cm，头颈部约占三分之一，腹背部宽6-11cm，尾长6-12cm。头略呈扁三角状，两眼多凹陷成窟窿，口内有细齿生于颚的边缘，无异型大齿。吻部半圆形，吻鳞不切鼻孔。背部呈灰黑色或银灰色，有黄白色或灰绿色斑点。四足均具5趾，趾间仅具蹼迹，足趾底有吸盘。尾细而坚实，有6-7个明显的银灰色环带。全身密被圆形或多角形微有光泽的细鳞，气腥，味微咸。
