# 苦菜性味归经与主治机理

苦菜禀天地阴气，味苦气寒，入心、脾、肾三经。其主治五脏邪气是因邪热客于心，胃痹渴热是因热在胃，肠癖是因热在大肠，恶疮是因热瘀伤血肉。苦寒总除诸热。
