# 金樱子性状鉴别要点

金樱子呈倒卵形，表面红黄色或红棕色，有突起的棕色小点（毛刺脱落残基），顶端有盘状花萼残基，中央有黄色柱基，下部渐尖，质硬。切开后花托壁内有多数坚硬小瘦果，内壁及瘦果均有淡黄色绒毛。气微，味甘、微涩。
