# 陶隐居区分石蜜、木蜜、土蜜

陶隐居云石蜜即崖蜜，高山岩石间作之，色青赤，味小酸，食之心烦，其蜂黑色似虻。木蜜呼为食蜜，悬树枝作之，色青白。土蜜于土中作之，色青白，味酸。
