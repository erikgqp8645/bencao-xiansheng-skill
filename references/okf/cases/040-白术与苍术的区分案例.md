# 白术与苍术的区分案例

白术性优，苍术性劣，凡欲补脾，则用白术，凡欲运脾，则用苍术。白术味甘，苍术兼苦，白术止汗，苍术发汗。二者并非一种，其苗、叶、根、茎均有区别。
