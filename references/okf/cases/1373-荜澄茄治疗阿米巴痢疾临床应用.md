# 荜澄茄治疗阿米巴痢疾临床应用

将荜澄茄子连皮研细装胶囊，每次1克，隔2小时1次，每日4次，连服3-5日。治疗60例，42例复查大便中38例未再发现阿米巴原虫，症状消失。
