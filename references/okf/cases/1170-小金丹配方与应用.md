# 小金丹配方与应用

小金丹：白胶香（煎膏）、草乌、五灵脂、地龙肉、木鳖子（去皮）各150g，乳香、没药、当归各75g，香墨12g，麝香30g。功能活血、消结、散毒，用于瘰疬乳岩，横痃，贴骨疽等症。每次2丸，每日2次，黄酒送服。忌饮烧酒及食生冷，孕妇勿服。
