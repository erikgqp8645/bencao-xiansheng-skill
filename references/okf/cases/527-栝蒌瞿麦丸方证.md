# 栝蒌瞿麦丸方证

张仲景治小便不利有水气、其人苦渴者，用栝蒌瞿麦丸，方含栝蒌根二两、大附子一个、茯苓山芋各三两、瞿麦一分，蜜丸如梧子大，一服三丸日三，以小便利、腹中温为知。
