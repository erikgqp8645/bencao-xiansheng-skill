# 曼陀罗治疗精神分裂症

将曼陀罗花制成10%酊剂或20%煎剂，每日早餐后服1次，连服6天停服1天，用量由10毫升逐渐增至40-80毫升。对62例精神分裂症患者观察，单独使用疗效似不高，但对精神运动性兴奋有良好的宁静作用。
