# 石榴皮治疗多种感染性炎症

石榴皮制成100%煎液烘干研粉装胶囊，每日3次每次1-2粒，治疗肠炎、胆道感染、气管炎等共415例，痊愈305例，基本痊愈57例，好转36例，无效17例。
