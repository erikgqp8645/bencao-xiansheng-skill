# 莪术性状特征

根茎圆锥形，上端较尖，下端基部钝圆，表面淡黄色，上部有明显环节，节上有鳞片样叶柄残基，两侧各有1列圆点状侧生根痕。质坚实，断面灰褐色，蜡样，常附有灰棕色粉末。内皮层环圆形，中柱占大部分。
