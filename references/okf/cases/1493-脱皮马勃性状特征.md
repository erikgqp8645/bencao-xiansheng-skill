# 脱皮马勃性状特征

脱皮马勃呈扁球形或类球形，无不孕基部，直径15-20cm，包被灰棕色至黄褐色，纸质，孢体灰褐色或浅褐色，紧密有弹性，手撕有棉絮状丝状物，触之孢子呈尘土样飞扬，手捻有细腻感，气似尘土，无味。
