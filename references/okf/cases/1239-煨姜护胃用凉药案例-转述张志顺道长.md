# 煨姜护胃用凉药案例（转述张志顺道长）

胃大热需要下凉药时，考虑胃不能受凉东西，这时候就要下煨姜。煨姜能护住胃，当服用凉药来治胃热时，凉药的药性都结束离开胃了，煨姜的药性都还能够保持在胃中。
