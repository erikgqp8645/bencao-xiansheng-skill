# 治鼻中息肉方

生地胆十枚，细辛半分（末），白芷半分（末）。以地胆压去汁，和药末涂于息肉之上，取消为度。亦单以地胆汁于竹简中盛，当上灌之。无生者，即酒煮汁用之。（《圣惠方》）
