# 柿蒂治呃逆附方

柿蒂配伍丁香、人参等可治呃逆，如柿钱散；单用烧灰存性黄酒调服亦治呃逆不止；另有柿蒂汤治伤寒呕哕、济生方柿蒂汤治胞满咳逆等。
