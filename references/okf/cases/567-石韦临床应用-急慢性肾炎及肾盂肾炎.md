# 石韦临床应用：急慢性肾炎及肾盂肾炎

用有柄石韦叶煎剂或片剂治疗急性肾小球肾炎39例，36例有效；肾盂肾炎20例，17例有效。服药2～3天后，尿量即增多，浮肿逐渐消退。
