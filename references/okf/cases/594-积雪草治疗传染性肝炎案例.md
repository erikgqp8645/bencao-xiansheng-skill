# 积雪草治疗传染性肝炎案例

取鲜积雪草4两，加水500毫升，浓煎成250毫升，趁热加入冰糖2两溶化，分2次空腹服，7天为一疗程。治疗10例，服药4天黄疸消退、食欲改善、恶心呕吐消失者3例，服药1周黄疸消退、消化道症状好转、胃纳增进者5例。
