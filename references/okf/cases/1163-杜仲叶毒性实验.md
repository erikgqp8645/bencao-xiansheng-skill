# 杜仲叶毒性实验

杜仲叶水煎剂小鼠腹腔注射的半数致死量为8.64±0.59g/kg。每日给小鼠灌服杜仲叶水煎醇沉液40g/kg连服3天，未见异常。杜仲水煎醇沉液12g/kg给大鼠灌胃连续21天，未发现有组织学改变。
