# 临床治丝虫病：榧子肉配血余灰为丸

榧子肉5两、头发灰1两，研末调蜜搓成150丸，日服3次每次2丸，4天一疗程。观察20例，第一疗程后微丝蚴转阴4例，第二疗程后转阴9例，其余大部分好转。
