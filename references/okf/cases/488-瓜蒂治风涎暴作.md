# 瓜蒂治风涎暴作

治风涎暴作，气塞倒卧。用瓜蒂为末，每用一二钱匕，腻粉一钱匕，以水半合调匀灌之。服药良久涎未出，含沙糖一块，下咽即涎出。此物甚不损人，全胜石碌、砂辈。
