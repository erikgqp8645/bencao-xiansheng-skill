# 治疗慢性气管炎案例

用白砒3分，白矾、淡豆豉各3钱共研细末，制成散剂、丸剂或胶囊。成人每天0.5克，睡前冷开水送服，100天为一疗程。治疗69例，临床治愈7例，显效20例，好转35例。副作用严重者停药后自行消失。
