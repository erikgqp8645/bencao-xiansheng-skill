# 蛇蜕治疗流行性腮腺炎

蛇蜕2钱（成人及12岁以上加倍）切碎加2个鸡蛋炒熟一次服用。90例患者除5例服2剂外均只服1剂，81%病例于治疗2日内腺肿消退。
