# 香附治心气痛腹痛方

治心气痛、腹痛、少腹痛、血气痛不可忍者：香附二两，蕲艾叶半两，以醋汤同煮熟，去艾，炒为末，米醋糊为丸梧子大，每白汤服五十丸。
