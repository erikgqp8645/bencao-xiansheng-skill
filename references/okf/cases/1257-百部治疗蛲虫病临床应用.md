# 百部治疗蛲虫病临床应用

小儿每次用百部1两，加水浓煎成30毫升（成人用量加倍），于夜间11时左右作保留灌肠，10～12天为一疗程。通过133例观察，治愈者占62%。如辅以使君子粉和大黄浸泡液内服，则疗效可显著提高。
