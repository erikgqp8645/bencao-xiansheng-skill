# 蚤休治疗外科炎症案例

用蚤休块根制成每毫升含生药2克的注射液，肌肉注射，每次2-4毫升，每日2-3次。治疗过敏性皮炎、痈疖、蜂窝织炎、急性淋巴结炎共37例，痊愈27例，好转6例，无效4例。
