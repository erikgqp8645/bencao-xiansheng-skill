# 小蓟治疗传染性肝炎

取小蓟干根1两或鲜根2两，水煎0.5~1小时，过滤加糖，睡前顿服，20~30天为一疗程；治疗221例，急性有效率77.9%，迁延性42.8~69%，慢性2%；但对重症黄疸病例似有相反结果。
