# 肉豆蔻的性状特征

肉豆蔻呈卵圆形或椭圆形，表面灰棕色或灰黄色，有时外被白粉（石灰粉末），全体有浅色纵行沟纹及不规则网状沟纹，断面显棕黄色相杂的大理石花纹，气香浓烈，味辛。
