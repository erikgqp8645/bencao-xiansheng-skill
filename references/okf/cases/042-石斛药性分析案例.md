# 石斛药性分析案例

石斛生于石上，得水长生，是禀水石之专精而补肾。味甘色黄，不假土力，是夺中土之气化而补脾。主治伤中者，营运其中土也。除痹者，除皮脉肉筋骨五脏外合之痹证也。
