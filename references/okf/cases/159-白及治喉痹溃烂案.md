# 白及治喉痹溃烂案

一女子年五旬，血虚生热化风，患喉痹，喉中血泡破尽，喉皆溃烂。诸药养阴退阳，活血祛风，后于吹药中入白及磨浆，合丸如芡实大，日夜嚙化之，遂一切所患皆愈。
