# 射干麻黄汤证

《金匮》射干麻黄汤治咳而上气，喉中如水鸡声。病机为风寒外闭，肺气郁迫，逆而上行，喉窍窄狭。方用射干、紫菀、款冬、五味、细辛、生姜、半夏下冲逆破壅塞，大枣补里，麻黄泻表。
