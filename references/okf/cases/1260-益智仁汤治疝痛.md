# 益智仁汤治疝痛

治疝痛，连小腹挛搐，叫呼不已：益智仁、干姜（炮）、甘草（炙）、茴香（炒）各三钱，乌头（炮，去皮）、生姜各半两，青皮（去白）二钱。上细切。每服四钱，水二盏，入盐少许，煎至七分，去滓，空心食前温服。（《济生方》益智仁汤）
