# 西洋参商品规格：粉光与原皮

西洋参因加工不同分为粉光西洋参（撞去外皮，硫黄熏后色白起粉）与原皮西洋参（连皮晒干或烘干）。二者各有野生与栽培之分，性状与品质有差异。
