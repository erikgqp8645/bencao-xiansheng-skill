# 白豆蔻的性状特征

白豆蔻果实呈圆球形，具不显著钝三棱，直径约1.2-1.7厘米，外皮黄白色，光滑，具隆起的纵纹25-32条，内含种子20-30粒集结成团，习称“蔻球”，分为3瓣，每瓣种子7-10粒，习称“白蔻仁”或“蔻米”。
