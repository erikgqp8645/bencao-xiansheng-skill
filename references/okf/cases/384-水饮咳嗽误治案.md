# 水饮咳嗽误治案

陈修园治一孀居咳嗽患者，前医服生地、麦冬、百合等一年不效。诊见脉细小而弦紧，断为水饮咳嗽，预言不治将水肿。后果然水肿大作，他医以槟榔、牵牛等攻逐，肿消而人瘦如柴，终至大汗呕逆气喘欲绝。陈修园以《金匮》桂苓甘术汤小剂应之，但病已不可为，后殁。
