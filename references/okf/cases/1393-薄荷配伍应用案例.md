# 薄荷配伍应用案例

风热表症、身不出汗、头痛目赤，常与荆芥、桑叶、菊花、牛蒡子等配合；风寒感冒身不出汗，可配合紫苏、羌活；风热咽痛常配合牛蒡子、马勃、甘草，也可研末吹喉；助麻疹透发可配合荆芥、牛蒡子、蝉衣。
