# 虎杖治疗烧伤临床应用

虎杖外用能促使创面迅速愈合，具有抗绿脓杆菌作用。34例烧伤面积18-40%患者，用药6-7天可治愈；21例Ⅰ、Ⅱ、Ⅲ度烧伤患者，未感染者7天左右脱痂痊愈，已感染者大部分10-14天痊愈。制剂为虎杖粉与茶液调匀涂创面，药痂下有感染时早期开窗引流或剪去部分药痂，改用100%虎杖煎液湿敷。
