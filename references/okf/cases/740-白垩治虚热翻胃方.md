# 白垩治虚热翻胃方

治虚热翻胃：用白垩土一斤，米醋一斤。煅土赤，入醋内，再煅再入，以醋干为度；取土二两，入炮姜一钱为末。每服一钱，米饮下，甚者二钱，须服四两。
