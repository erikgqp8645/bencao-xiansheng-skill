# 蛇含治疗肠梗阻的临床应用

取鲜蛇含全株4两捣烂绞汁，冲入等量童便，稍加热缓缓服下；冬季用干品2两作煎剂冲童便内服。服药后呕吐应补足药量，小量多次服药，一般第2次即不呕吐，24小时内见效。
