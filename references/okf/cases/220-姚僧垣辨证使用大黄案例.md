# 姚僧垣辨证使用大黄案例

梁武帝发热欲服大黄，姚僧垣以年高不可轻用劝阻，帝不从几至委顿；元帝心腹疾，诸医谓宜平药，僧垣诊脉洪而实断为有宿妨，非用大黄不差，帝从之遂愈。
