# 交感丹治心肾不交

记载交感丹方，治凡人中年精耗神衰，心血少火不下降，肾气惫水不上升，致心肾隔绝，营卫不和。用香附子一斤、茯神四两，炼蜜丸弹子大，以降气汤送服。俞通奉年五十一服此，老犹如少，年至八十五乃终。
