# 治疗支气管哮喘案例

取健康产妇胎盘，洗净后低温干燥，研成细末或制成丸备用。每日6-12克，分3次饭后服。试治2例，均获近期治愈。另有胎盘血穴位注射法，试治8例，7例有效。
