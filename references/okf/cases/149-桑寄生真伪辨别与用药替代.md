# 桑寄生真伪辨别与用药替代

真桑寄生须近海桑树、节间自然生出、缠附桑枝；碎实有汁稠粘或折茎色深黄者为真。市售多采木寄生冒充，且川独活常被土当归假代，导致古方无效。
