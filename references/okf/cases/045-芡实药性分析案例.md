# 芡实药性分析案例

芡实气味甘平，子黄仁白，生于水中，花开向日，乃阳引而上，阴引而下，故字从欠，得阳明少阴之精气。主治湿痹者，阳明之上，燥气治之也。治腰脊膝痛者，少阴主骨，外合腰膝也。
