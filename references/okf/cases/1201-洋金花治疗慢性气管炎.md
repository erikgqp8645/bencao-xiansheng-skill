# 洋金花治疗慢性气管炎

用洋金花注射液每5天肌注1次，每次含东莨菪碱0.5-1.0毫克，共治疗慢性气管炎1200例，临床控制率为70%，显效率为17%，用药后心、肝、肾功能未见损害。
