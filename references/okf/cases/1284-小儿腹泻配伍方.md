# 小儿腹泻配伍方

小儿腹泻：炒谷芽9g、木香6g、诃子肉5g、葛根5g、通草2g。上药水煎，日分2次服。对症加味：挟热加白芍、黄芩；体虚加沙参、白术；溢奶或吐清水加丁香、柿蒂。
