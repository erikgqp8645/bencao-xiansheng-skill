# 冬葵子复方应用示例

列举多个复方：治卒关格大小便不通用葵子二升水四升煮服；治大便不通用葵子末入乳汁和服；治妊娠子淋用葵子一升水三升煮服；治妊娠水气用葵子茯苓散；治难产用冬葵子捣破煮服；治胎死腹中用葵子阿胶煮服；治乳汁不行用葵菜子炒香与缩砂仁等分为末热酒服。
