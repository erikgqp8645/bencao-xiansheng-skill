# 万州黄药子治瘿疾案例

《本草图经》引孙思邈《千金月令》记载以万州黄药子半斤，用无灰酒一斗浸泡，糠火烧一复时，患者时时饮一盏，三五日后以镜自照，觉销即停饮，否则项细。
