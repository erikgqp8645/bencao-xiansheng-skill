# 细辛的临床应用配伍

细辛主要能散寒止痛，常与羌活、荆芥、川芎等同用治疗外感风寒头痛；与白芷、石膏等同用治齿痛；与羌活、川乌、草乌等配伍治寒湿风湿痹痛。能温肺化痰饮，用于肺寒咳嗽、痰多质稀色白，常与干姜、半夏等配伍。
