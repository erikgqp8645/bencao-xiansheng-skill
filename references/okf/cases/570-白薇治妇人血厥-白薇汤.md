# 白薇治妇人血厥（白薇汤）

妇人血厥，平居无疾苦，忽如死人，目闭口噤，或微知人，眩冒移时方寤。因出汗过多，血少，阳气独上，气塞不行所致。用白薇汤：白薇、当归各六钱，人参半之，甘草又半之。
