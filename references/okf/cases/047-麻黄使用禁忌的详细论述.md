# 麻黄使用禁忌的详细论述

麻黄为发散第一药，但使用时需严格辨证。非冬月、无寒邪、寒邪在里或伤风等证，虽有发热恶寒但不头痛身疼拘急、六脉不浮紧者，皆不可用。即使可汗之证，亦不宜多服，以防过汗亡阳或血溢。
