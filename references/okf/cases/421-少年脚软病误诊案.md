# 少年脚软病误诊案

一少年新娶后得脚软病且疼甚，医者误作脚气治不效。后以杜仲一两，半酒半水煎服，三日能行，又三日痊愈。此案说明杜仲可治肾虚腰痛，且以酒行之则效容易。
