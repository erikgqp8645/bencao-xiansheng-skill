# 瓦松治鼻衄方

治鼻衄：取鲜瓦松二斤，洗净阴干捣烂，纱布绞汁，加砂糖五钱拌匀，晒干成块。每次服五分至一钱，每日二次，温开水送服。忌辛辣刺激食物和热开水。
