# 临床治钩虫病：每日吃炒榧子3~5两

每日吃炒榧子3~5两，直至大便中虫卵消失。曾治5例（3例兼有鞭虫），皆经1月左右痊愈，未见副作用。配合使君子肉、蒜瓣煎服疗效更佳。
