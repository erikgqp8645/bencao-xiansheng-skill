# 阿魏治气积肉积方

治气积，肉积，心腹膨满，结块疼痛，或引胁肋疼痛，或痛连背膂，不思饮食：木香（不见火）、槟榔各半两，胡椒、阿魏（用醋化开）各二钱半。上为细末，用阿魏膏子，并粟米饭，杵和为丸，如桐子大。每服四十丸，不拘时候，生姜皮汤下。
