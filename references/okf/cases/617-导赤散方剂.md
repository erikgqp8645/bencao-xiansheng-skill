# 导赤散方剂

导赤散出自《小儿药证直诀》，清心养阴，利水通淋，主治心经热盛，心胸烦热，口渴面赤，意欲冷饮，以及口舌生疮，或心热移于小肠，症见小溲赤涩刺痛。
