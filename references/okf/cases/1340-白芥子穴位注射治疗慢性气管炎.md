# 白芥子穴位注射治疗慢性气管炎

用10%或20%白芥子注射液穴位注射，每次选2-3穴，每穴0.5-1毫升，每日1次，7-10天为一疗程。喘息型以膻中、定喘、肺俞、天突为主，单纯型以天突、中腑、肺俞为主。149例总有效率：单纯型75.7%，喘息型84.9%。平喘作用较好，无明显消炎作用。
