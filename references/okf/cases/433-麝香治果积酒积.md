# 麝香治果积酒积

麝香能消水果之伤，但实为杀虫之效。食果过多，胸中未有不生虫者，生虫则必思果，思果则必多食果。前人用麝香而食果之病痊，遂疑麝香能消果，谁知是杀虫之效。酒得麝则败，故治酒积。
