# 芦荟治疗臭鼻症临床应用

以2%地卡因浸湿棉片贴附注射部位5-10分钟，然后用20%芦荟浸出液注射于两侧下鼻甲前端粘膜下，每侧注射2毫升，每周1次，4次为一疗程。观察48例，大多数病人主要症状如结痂、恶臭、头昏、头痛等均有不同程度改善，少数无效。
