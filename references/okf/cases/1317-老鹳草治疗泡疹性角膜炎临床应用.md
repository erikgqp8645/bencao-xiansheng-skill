# 老鹳草治疗泡疹性角膜炎临床应用

用西伯利亚老鹳草制成20%眼药水治疗盘状角膜炎等25例，显效15例，有效10例；对浅层点状及树枝状角膜炎6例，显效3例，有效1例，无效2例。
