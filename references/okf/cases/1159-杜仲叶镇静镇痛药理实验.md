# 杜仲叶镇静镇痛药理实验

杜仲叶煎剂20g/kg给小鼠灌胃后1、2、3小时，自发活动次数明显减少，以2小时最明显。热板法实验证实小鼠腹腔注射杜仲叶水煎醇沉液12g/kg能提高致痛阈，有明显镇痛作用。
