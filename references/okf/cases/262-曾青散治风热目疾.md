# 曾青散治风热目疾

治风热目疾（眼红或烂，怕太阳光，眼屎多，常流泪，或痒或痛），用曾青四两，蔓荆子二两，炮姜、防风各一两，共研细，经常以少许吸入鼻中，有效。
