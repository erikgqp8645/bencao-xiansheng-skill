# 紫色马勃性状特征

紫色马勃呈陀螺形或压扁呈扁圆形，直径5-12cm，不孕基部发达，包被薄，两层，紫褐色，粗皱，有圆形凹陷，外翻，上部常裂成小块或已部分脱落，孢体紫色。
