# 木贼治疗牛皮癣临床应用

木贼注射液，每次肌肉注射2毫升，每日2次，半月为一疗程；如无不良反应，可连续应用。治疗99例，基本痊愈4例，显效49例。疗效最快者经注射15次后即达到基本治愈，但一般需注射70～80次。
