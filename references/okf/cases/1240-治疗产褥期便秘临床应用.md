# 治疗产褥期便秘临床应用

取番泻叶2.5钱，冲开水约150毫升，经2-5分钟，弃渣1次服下；如便秘时间过久，隔10分钟后将药渣再泡服1次。治疗100例，多数服1次即见效，少数有轻度下腹疼痛，未见乳汁减少、恶露增多等不良影响，但平素脾胃虚弱者不宜服用。
