# 归脾汤治思虑劳伤心脾

《本草纲目》记载归脾汤方：龙眼肉、酸枣仁（炒）、黄芪（炙）、白术（焙）、茯神各一两，木香半两、炙甘草二钱半，切细。每服五钱，加姜三片、枣一枚、水二盅煎成一盅，温服。治思虑过度，劳伤心脾，健忘怔忡，虚烦不眠，自汗惊悸。
