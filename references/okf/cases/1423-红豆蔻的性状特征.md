# 红豆蔻的性状特征

红豆蔻为高良姜种子，果实长圆形，中部稍收缩，表面红棕色或淡红棕色，果皮薄易碎，种子呈三角状多面体，表面暗棕色或褐棕色，外被淡黄色或灰黄色假种皮，气芳香而浓，味辛、辣。
