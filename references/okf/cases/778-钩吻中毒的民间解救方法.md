# 钩吻中毒的民间解救方法

误食钩吻叶，饮冷水即死，以死尸悬树上汁滴在地即生菌子，收之名菌药。蕹菜捣汁解之，取蕹菜汁滴野葛苗即萎死。中野葛毒，急不可得蕹菜，多饮甘草汁、人屎汁，或白鸭血、白鹅血、羊血灌之亦解。
