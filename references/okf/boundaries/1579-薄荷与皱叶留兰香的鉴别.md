# 薄荷与皱叶留兰香的鉴别

皱叶留兰香常被误认为薄荷，但薄荷气味更清凉刺激，叶面更平整、褶皱较少；留兰香为入侵物种，在中国仅新疆有野生，其他省区为栽培。
