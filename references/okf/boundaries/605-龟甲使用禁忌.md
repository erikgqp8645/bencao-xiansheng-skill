# 龟甲使用禁忌

肾虚无热者、孕妇忌用；阴虚燥热者禁用；脾胃虚寒、真精冷滑者禁用龟胶；病患虚而无热者不宜服；新剖之甲有毒不宜轻使；十二月忌服。
