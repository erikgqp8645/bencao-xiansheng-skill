# 九里香与千里香显微鉴别差异

九里香栅栏细胞2-3列，内含多数草酸钙簇晶，直径12-20μm；中脉维管束双韧型，导管呈放射状排列，油室直径80-120μm。小叶九里香小叶片最宽处通常在中部以上，先端圆或钝。
