# 当归禁忌：肠胃薄弱、泄泻溏薄者忌

当归辛温行走之性，故致滑肠。其气与胃气不相宜，故肠胃薄弱，泄泻溏薄，及一切脾胃病，恶食，不思食及食不消，并忌之。
