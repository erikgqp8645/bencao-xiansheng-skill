# 小蓟治疗肝炎的禁忌

恶性肝炎（包括肝昏迷）、明显肝功能不良者、肝炎患者合并胃肠道出血、活动性肺结核、急性胃炎、恶性高血压、心力衰竭及妊娠后期的妇女应禁忌使用小蓟。
