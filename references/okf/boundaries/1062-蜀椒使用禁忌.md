# 蜀椒使用禁忌

非命门火衰、中气寒冷者大忌；阴虚火旺之人忌服；肺胃素有火热、咳嗽生痰、大肠积热下血者不宜用；泄泻由于火热暴注而非积寒虚冷者忌之。
