# 柴胡使用的误区和警示

柴胡为少阳经半表半里之药，病在太阳者服之太早会引贼入门，病在阴经者复用会重伤其表。世俗常混用柴胡治疗伤寒，导致致命后果。劳证唯肝经者可用，气虚者仅作少量辅助，不可作为退热主药。
