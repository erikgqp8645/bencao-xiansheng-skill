# 黄连使用禁忌

凡病人血少气虚，脾胃薄弱，泄泻腹痛者，犯之危殆。胃中停食受寒及伤寒下早致痞，俱不可用。除肠红因湿热者固宜，若阴虚下血及损脾血下者，俱禁用。虚寒为病者大忌。
