# 北葶苈与南葶苈的性状鉴别

北葶苈子（独行菜种子）呈扁卵形，表面棕色或红棕色，微有光泽，具纵沟2条，一端钝圆，另端尖而微凹，类白色，种脐位于凹入端，味微辛辣，黏性较强；南葶苈子（播娘蒿种子）呈长圆形略扁，一端钝圆，另端微凹或较平截，味微辛、苦，略带黏性。
