# 升麻与犀角替代之辨

朱肱言瘀血入里吐衄血者，犀角地黄汤如无犀角可代以升麻。但朱二允指出升麻性升、犀角性降，用犀角止血是借其下降之气清心肝之火，误用升麻则血随气升，涌出不止，古方未可尽泥。
