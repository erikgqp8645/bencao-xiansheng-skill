# 熟地黄不宜用于汤剂及养血凉血方

地黄专取其性凉而滑利流通，熟则腻滞不凉全失其本性矣。仲景伤寒一百十三方，惟复脉用地黄，因伤寒之病，邪从外入，最忌滋滞。
