# 麝香使用禁忌

麝香走窜，能泄卫气、泄营，诸证属虚者概弗施用。如不得已借以开通开窍，亦宜少用。孕妇不宜佩带，劳怯人亦忌之。不可近鼻，有白虫入脑患癞。久带其香透关，令人成异疾。
