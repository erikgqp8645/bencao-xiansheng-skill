# 白蒿与茵陈的品种争议

网络说法不一，有说白蒿与茵陈是同一株植物（依据'三月茵陈四月蒿'），也有说不是同一株，真正的茵陈开黄色花朵。作者认为抖音创作者'嵩山采药人'的说法与《神农本草经》性味记载较匹配，故白蒿取图为'毛茵陈'，茵陈取图为'黄花茵陈'。
