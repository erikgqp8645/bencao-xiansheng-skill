# 青葙子禁忌：瞳子散大者忌服

多部本草著作（《本草撮要》《药性切用》《本草求真》《得配本草》《本草备要》）及《中药学》均记载瞳子散大者忌服或禁用青葙子，因其有扩散瞳孔的作用，且恐散阴气、助火。
