# 红景天化学成份

库页红景天根和茎含酪醇和毛柳甙（红景天甙）；圣地红景天根分离出13种成分，包括咖啡酸、伞形花内酯、酪醇、没食子酸、山奈酚、β-谷甾醇、胡萝卜甙及红景天甙等。
