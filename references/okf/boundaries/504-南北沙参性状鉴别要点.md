# 南北沙参性状鉴别要点

北沙参呈细长圆柱形，表面淡黄白色，断面皮部浅黄白色、木部黄色；南沙参呈圆锥形或圆柱形，略弯曲，体轻质脆，断面不平坦、多裂隙。
