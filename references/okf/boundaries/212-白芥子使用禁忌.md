# 白芥子使用禁忌

白芥子味极辛气温，能搜剔内外痰结及胸膈寒痰冷涎，但肺经有热与阴火虚炎咳嗽生痰者忌用；茎叶煮食动风动气，有疮疡痔疾便血者忌之。
