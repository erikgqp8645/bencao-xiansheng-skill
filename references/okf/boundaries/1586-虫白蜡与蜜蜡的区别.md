# 虫白蜡与蜜蜡的区别

虫白蜡与蜜蜡不同，虫白蜡味甘不淡而温，蜜蜡味甘淡涩微温；蜜蜡有涩性可止渴治痢，虫蜡涩性差减而痢则鲜用。
