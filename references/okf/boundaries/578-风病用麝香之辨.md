# 风病用麝香之辨

风病不同，有入于骨者，有入于皮肉者，有入于脏腑者，未可一概用麝香而走窜之。风入于骨髓者，不得已而用麝香，使攻邪之药直入骨髓，祛风外出，此治真正中风。其余风邪不过在脏腑之外、肌肉之间，使亦用麝香引风入骨，反致变生大病。
