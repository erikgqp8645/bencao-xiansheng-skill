# 杜若与杜蘅的品种区别

《证类本草》引图经指出杜若与杜衡（杜蘅）为不同品种，杜若为《广雅》所谓楚衡，杜衡为《尔雅》所谓土卤，古人多相杂引用，但实为两类。
