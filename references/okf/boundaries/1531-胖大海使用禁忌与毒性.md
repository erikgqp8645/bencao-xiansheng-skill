# 胖大海使用禁忌与毒性

曾有服用胖大海20g沸水浸泡液致过敏的报道，服后2小时左右全身发痒，皮肤潮红，伴头晕、心慌、胸闷、恶心、口唇水肿等过敏症状。小鼠口服半数致死量为12.96g/kg。
