# 补骨脂禁忌与不适宜人群

阴虚火旺者忌服。阴虚火动、梦遗、尿血、小便短涩、目赤口苦舌干、大便燥结、内热作渴、火升目赤、易饥嘈杂、湿热成痿、骨乏无力者皆不宜服。阴虚下陷、内热烦渴、眩晕气虚、怀孕心胞热、二便结者禁用。
