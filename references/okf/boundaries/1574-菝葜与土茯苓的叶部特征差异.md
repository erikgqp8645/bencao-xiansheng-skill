# 菝葜与土茯苓的叶部特征差异

菝葜叶革质，圆形乃至广椭圆形，下面绿色；土茯苓叶革质，狭椭圆状披针形，下面通常淡绿色，叶面光滑带有白色斑点（大多数），叶子背面白色。
