# 菥蓂子药材性状鉴别

《中药大辞典》记载干燥种子黑褐色，细小，长约1.5毫米，表面有向心隆起的环纹，无毛；以籽粒饱满、黑色、干燥、无灰土杂质者为佳。《中华本草》补充种扁圆形，表面棕黑色，两面各有5-7条突起偏心性环纹。
