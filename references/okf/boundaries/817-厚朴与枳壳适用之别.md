# 厚朴与枳壳适用之别

厚朴从苦温以散结，宜于寒湿；枳壳从苦寒以泄滞，宜于热燥。施厚朴于燥热之结犹可借从治奏功，施枳壳于寒湿则气本下而复降之，不惟无益而有害。
