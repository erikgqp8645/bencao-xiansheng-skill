# 马鞭石斛性状特征

马鞭石斛茎细长圆锥形，上部有少数分枝，表面棕黄色，有8-9条纵沟，质疏松，断面纤维性，气微，味微苦，商品常切成1.5~3cm长段，切面灰白色。
