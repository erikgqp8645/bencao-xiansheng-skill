# 木贼与麻黄的区别

木贼形质有类麻黄，升散亦颇相似，但木贼气不辛热，且入足少阳胆、足厥阴肝，能于二经血分驱散风热，使血上通于目，为去翳明目要剂；麻黄味辛性燥，专开在卫腠理而使身汗大出。
