# 三棱与荆三棱（黑三棱）的区分

黑三棱科三棱（京三棱）形如鲫鱼而体重；莎草科荆三棱（黑三棱）形如乌梅而体轻。荆三棱块茎呈近球形，表面棕黑色，质轻而坚硬，入水中漂浮于水面，稀下沉。
