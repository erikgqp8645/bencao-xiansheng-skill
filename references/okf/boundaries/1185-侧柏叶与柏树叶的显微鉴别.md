# 侧柏叶与柏树叶的显微鉴别

柏树叶与侧柏叶主要区别为：表皮和皮层有较多的含棕色物质的细胞，转输管胞的具缘孔少、草酸钙结晶主要为砂晶，偶见片状或柱状结晶。
