# 白果中毒表现与解救

白果中毒可出现发烧、呕吐、腹泻、惊厥、抽搐、肢体强直、皮肤青紫、瞳孔散大、脉弱而乱，甚者昏迷。解救方法包括洗胃、导泻、服鸡蛋清、活性炭，并对症处理如给氧、镇静剂、兴奋剂等。
