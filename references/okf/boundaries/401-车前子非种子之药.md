# 车前子非种子之药

五子衍宗丸用车前子者，因枸杞、覆盆过于动阳，菟丝、五味子过于涩精，故用车前以小利之。用通于闭之中，用泻于补之内，始能利水而不耗气。非车前之自能种子也。
