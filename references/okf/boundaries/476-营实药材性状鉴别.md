# 营实药材性状鉴别

果实卵圆形，长约6-8毫米，外皮红褐色，内为肥厚肉质果皮，种子黄褐色，果肉与种子间有白毛，果肉味甜酸。以个大、均匀、肉厚、无杂质者为佳。
