# 菥蓂与大荠、葶苈的品种辨析

《本草图经》引苏恭说菥蓂即大荠，但菥蓂味辛、大荠味甘；陈藏器认为大荠即葶苈，非菥蓂，菥蓂大而扁，葶苈细而圆，二物不同。
