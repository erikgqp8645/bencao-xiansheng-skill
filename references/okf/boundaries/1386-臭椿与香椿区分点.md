# 臭椿与香椿区分点

臭椿树茎杆、枝干相对更光滑；臭椿树茎杆分枝较多，而香椿树一般是直立向上生长，在顶部再长分枝；臭椿叶子虽双数对生但末端只有一片叶子，香椿叶子末端是两片；香椿嫩叶偏红光滑，老叶变绿，叶子味道香，臭椿叶子毛茸茸有臭味。
