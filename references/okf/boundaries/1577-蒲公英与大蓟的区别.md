# 蒲公英与大蓟的区别

蒲公英叶片形状有点像大蓟，但大蓟叶片周边有坚硬的倒刺，戳到人是比较痛的，叶片表面还有毛茸茸的绒毛；蒲公英叶片表面没有绒毛，周边也有锯齿状的东西，但并不戳人。叶片形状相似，但叶质不同。
