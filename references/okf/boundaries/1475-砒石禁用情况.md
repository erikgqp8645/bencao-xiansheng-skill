# 砒石禁用情况

疟疾邪未汗出、表邪未清，或久疟阴虚阳乏者；齁喘肺热里虚或兼阴虚劳损者；瘀肉不化因阳气不充、胃虚不食、痈疡见七恶而神气萎弱者，均不可用砒石。
