# 蟾酥毒性及中毒处理

蟾酥各种成分对小鼠半数致死量不同，静脉或腹腔注射蟾酥注射液，小鼠急性中毒为呼吸急促，肌肉痉挛，心跳不整，最后麻痹而死，阿托品对此有一定的解毒作用，肾上腺素则无，蟾酥经煮沸后毒性大减。人中毒后，可按洋地黄类强心药中毒时之急救原则处理。
