# 兰草与泽兰功用区别

兰草走气道，能利水、除痰癖、杀蛊辟恶，为消渴良药；泽兰走血分，治水肿、涂痈毒、破瘀血、消症瘕，为妇人要药。虽是一类，功用稍殊。
