# 鸡血藤膏来源非豆科鸡血藤

云南鸡血藤膏非豆科鸡血藤原植物的藤茎熬制而成，主要由木兰科南五味子属植物内南五味子和异型南五味子的藤茎切片熬膏而得。另有禄劝鸡血藤膏系豆科铁藤（巴豆藤）的藤茎熬制而得。由于药材来源不一，疗效也不一致。
