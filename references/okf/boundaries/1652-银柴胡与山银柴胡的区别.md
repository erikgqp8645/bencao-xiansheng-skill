# 银柴胡与山银柴胡的区别

除正品银柴胡外，尚有多种石竹科植物的根亦作银柴胡入药，统称山银柴胡，品质较次。包括丝石竹、锥花丝石竹、灯心草蚤缀、旱麦瓶草、蝇子草等。
