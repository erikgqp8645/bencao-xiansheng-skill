# 使君子使用注意与禁忌

服药时忌饮浓茶或热茶，犯之即泻。大量服用能引起呃逆、眩晕、精神不振、恶心，甚至呕吐、腹泻等反应。脾胃虚寒之子不宜多用，多食则发呃。苟无虫积，服之必致损人。
