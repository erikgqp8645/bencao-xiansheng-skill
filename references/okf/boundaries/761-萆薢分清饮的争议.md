# 萆薢分清饮的争议

《本草正义》指出杨氏萆薢分清饮专治湿热淋浊，但方中益智仁温而且涩，性正相反，不能并列，殊有误会。李时珍谓此方治真元不足下焦虚寒，与萆薢性情两相背谬。
