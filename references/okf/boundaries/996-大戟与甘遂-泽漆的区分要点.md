# 大戟与甘遂、泽漆的区分要点

三者统称猫眼三兄弟，可通过叶片区分：泽漆叶片倒卵形或匙形；甘遂叶片狭叶披针形或线状披针形，先端钝；大戟叶片长椭圆形，先端尖，基部近平截。泽漆为一年生草本，甘遂和大戟为多年生。
