# 鹤虱品种与产地差异

除正品北鹤虱（天名精果实）外，尚有南鹤虱（野胡萝卜果实）、华南鹤虱（窃衣果实）、东北鹤虱（紫草科植物果实）等不同品种，性状各异，产地不同。
