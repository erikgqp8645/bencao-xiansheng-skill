# 斑蝥不堪内服，只可外用

斑蝥辛咸性寒有大毒，走达下窍至精溺之处，能蚀下败物，破石淋、堕胎、拔瘰疬根、治疯犬毒，虽有方法，然终未免假借大毒之物，只可外用蚀死肌溃痈肿搽疯涂癣，不堪内服。
