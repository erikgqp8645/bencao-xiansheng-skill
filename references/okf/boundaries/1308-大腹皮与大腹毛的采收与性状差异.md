# 大腹皮与大腹毛的采收与性状差异

冬季至次春采收未成熟果实，煮后干燥，纵剖两瓣，剥取果皮，习称“大腹皮”；春末至秋初采收成熟果实，煮后干燥，剥取果皮，打松，晒干，习称“大腹毛”。二者性状不同：大腹皮外果皮深棕色至近黑色，具纵皱纹及横纹；大腹毛外果皮多已脱落或残存，中果皮棕毛状。
