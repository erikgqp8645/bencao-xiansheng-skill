# 沉香理化鉴别法

取醇溶性浸出物进行微量升华，得黄褐色油状物，香气浓郁；于油状物上加盐酸1滴与香草醛少量，再滴加乙醇1～2滴，渐显樱红色，放置后颜色加深。
