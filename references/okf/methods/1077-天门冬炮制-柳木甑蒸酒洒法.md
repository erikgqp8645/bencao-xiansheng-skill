# 天门冬炮制：柳木甑蒸酒洒法

《雷公炮炙论》记载天门冬炮制：去上皮，劈破去心，用柳木甑烧柳木柴蒸一伏时，洒酒令遍，再蒸一伏时，取出摊晒干。
