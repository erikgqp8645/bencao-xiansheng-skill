# 醋三棱炮制方法（辞典法）

取净三棱置开水锅内浸没，煮至五、六成透时，加醋再煮至八成透，停止加水，并停止续火，留在锅内闷透，吸尽余汤，捞出，晾至外皮无水分，切片，晒干。每三棱100斤，用醋30斤。
