# 金钱草临床应用配伍

热淋尤善治石淋，可单味浓煎代茶饮，或与海金沙、鸡内金同用；湿热黄疸与茵陈、栀子同用；胆石症配伍茵陈、黄芩、木香；疔疮肿毒、蛇虫咬伤用鲜品捣汁饮、渣外敷。
