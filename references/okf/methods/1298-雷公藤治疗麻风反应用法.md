# 雷公藤治疗麻风反应用法

雷公藤干根彻底去除内外两层皮，将木质部切片晒干。每用4钱，加水2500毫升，文火煎（不加盖）3～4小时，取褐色药液250毫升，早晚分服，3～4天为一疗程。
