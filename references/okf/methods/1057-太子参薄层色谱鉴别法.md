# 太子参薄层色谱鉴别法

取粉末加甲醇温浸，滤过浓缩作为供试品，与对照药材同法制备，点于硅胶G薄层板，以正丁醇-冰醋酸-水（4:1:1）展开，喷茚三酮乙醇溶液，105℃加热显色，供试品与对照药材相应位置显相同颜色斑点。
