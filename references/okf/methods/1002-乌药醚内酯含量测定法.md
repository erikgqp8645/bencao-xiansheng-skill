# 乌药醚内酯含量测定法

采用高效液相色谱法测定乌药醚内酯含量。色谱条件：十八烷基硅烷键合硅胶为填充剂，乙腈-水（56:44）为流动相，检测波长235nm，理论板数按乌药醚内酯峰计算应不低于2000。本品按干燥品计算，含乌药醚内酯不得少于0.030%。
