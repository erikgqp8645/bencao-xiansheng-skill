# 苏叶配人参治初感风寒之法

苏叶表散风邪，得人参相助则奏功如响。邪初入人体，正气尚能与邪战，用参助正气，则正气旺而得祛邪之便。但风寒已感三四日，则不可轻用人参，当看虚弱壮盛而用药。
