# 郁金市场流通与品质评价

温郁金和桂郁金最常用、量最大；黄丝郁金价格高、市场流通量不多。但综合评价黄丝郁金品质最好，香气浓郁。安宫牛黄丸最初用黄丝郁金，替换后效果打了折扣。
