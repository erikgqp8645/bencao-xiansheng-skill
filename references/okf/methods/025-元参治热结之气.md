# 元参治热结之气

元参所疗，皆本于气之化热，故为热所结之气，不限上下，不分虚实，皆可肃清。实为邪实，除邪不能全藉元参，则假元参化气之并于邪者；虚为正虚，补虚尤不可全藉元参，则假元参助气之歉于正者。
