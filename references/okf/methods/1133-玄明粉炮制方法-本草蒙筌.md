# 玄明粉炮制方法（本草蒙筌）

详细记载了玄明粉的炮制流程：朴硝溶化去油滤渣，加萝卜、冬瓜、豆腐煮沸多次，再滤净，瓦盆星月下生消芽，风干，反复煎煮至无消片，泥裹罐装炭火煅炼一昼夜。
