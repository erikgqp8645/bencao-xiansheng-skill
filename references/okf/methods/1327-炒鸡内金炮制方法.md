# 炒鸡内金炮制方法

取净鸡内金，照清炒或烫法炒至鼓起。炒后表面暗黄褐色至焦黄色，放大镜观察显颗粒状或微细泡状，轻折即断，断面有光泽，炒后去除腥味。
