# 金荞麦薄层色谱鉴别法

取粉末加氯仿浸渍，滤过，蒸干后加氯仿溶解作为供试品，与对照药材溶液点于硅胶G薄层板上，以氯仿-甲醇(19:1)展开，喷10%硫酸乙醇溶液加热显色，供试品与对照药材相应位置应显相同颜色斑点。
