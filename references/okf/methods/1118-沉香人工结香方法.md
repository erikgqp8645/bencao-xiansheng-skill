# 沉香人工结香方法

在树干上凿洞（宽2cm、长5-10cm、深5-10cm），用泥土封闭让其结香；或在树干同一侧从上到下每隔40-50cm开洞，用菌种塞满后塑料薄膜包扎封口，待上下伤口结香相连接时整株砍下采香。
