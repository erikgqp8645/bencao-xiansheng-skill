# 紫花地丁薄层色谱鉴别法

取粉末加甲醇超声处理，滤过，蒸干，加热水溶解，再蒸干，加甲醇溶解作为供试品溶液。以甲苯-醋酸乙酯-甲酸（5:3:1）上层溶液为展开剂，在硅胶G薄层板上展开，置紫外光灯（365nm）下检视，供试品色谱中应显3个相同颜色的荧光主斑点。
