# 《本草新编》论淫羊藿补命门火之辨

淫羊藿补命门之火，亦在肾之中，不在肾之外。妇人欲火盛非命门火旺，乃命门火衰，治方泻肝木之火乃一时权宜，肝木既平仍宜补命门之火。
