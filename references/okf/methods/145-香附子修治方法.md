# 香附子修治方法

李时珍记载香附子的修治方法：采得连苗曝干，以火燎去苗及毛。用时以水洗净，石上磨去皮，用童子小便浸透，洗晒捣用。或生或炒，或以酒醋盐水浸，诸法各从本方。又稻草煮之，味不苦。
