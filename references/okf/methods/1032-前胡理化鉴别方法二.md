# 前胡理化鉴别方法二

取粉末5g，加甲醇30ml，加热回流10分钟，滤过。取滤液2ml，蒸干，残渣加冰醋酸1ml使溶解，再加乙酰氯5滴和氯化锌数粒，置水浴中加热1-2分钟，溶液显红色。
