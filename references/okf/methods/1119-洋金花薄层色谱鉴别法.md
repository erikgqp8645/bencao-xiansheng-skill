# 洋金花薄层色谱鉴别法

取粉末加浓氨试液和氯仿提取，以硫酸阿托品与氢溴酸东莨菪碱为对照品，用醋酸乙酯-甲醇-浓氨试液（17:2:1）展开，喷稀碘化铋钾试液，供试品色谱中在与对照品相应位置显相同颜色斑点。
