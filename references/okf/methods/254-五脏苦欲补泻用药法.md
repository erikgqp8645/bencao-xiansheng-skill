# 五脏苦欲补泻用药法

根据《内经·脏气法时论》，五脏各有苦、欲，需用相应性味药物补泻。如肝苦急食甘以缓之（甘草），肝欲散食辛以散之（川芎），以辛补之（细辛），以酸泻之（芍药）。虚则补其母，实则泻其子。
