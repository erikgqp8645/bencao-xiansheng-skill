# 用药酒洗曝干与根梢身例

病在头面及手梢皮肤者，黄芩黄连黄柏知母须酒炒借酒力上腾；咽之下脐之上酒洗；在下生用。大凡生升熟降。大黄须煨恐寒损胃气，川乌附子须炮制毒。用药根梢：病在中上焦用根，下焦用梢，根升梢降。
