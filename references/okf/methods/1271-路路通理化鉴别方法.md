# 路路通理化鉴别方法

通过化学反应鉴别路路通：水提液加碱性酒石酸铜试液产生红色沉淀（检查糖类）；乙醇提取液加浓硫酸-醋酐试剂显红紫色（检查甾类）；加锌粉和浓盐酸显橙色（检查黄酮类）。
