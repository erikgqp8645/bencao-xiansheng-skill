# 桑白皮蜜炙炮制方法

蜜炙桑白皮：取桑白皮丝片，用炼蜜（桑白皮100kg用炼蜜25kg，加适量开水稀释）拌匀，稍闷，以文火炒至金黄色不粘手时，取出摊凉。蜜炙后缓和寒泻之性，增强润肺止咳作用。
