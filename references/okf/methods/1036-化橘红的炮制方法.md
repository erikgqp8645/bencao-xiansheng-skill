# 化橘红的炮制方法

化橘红的炮制方法有两种：一是拣去杂质，刷净，用时擘碎；二是蜜制，取蜂蜜文火炼老，加水适量，将橘红碎块倒入，拌包，炒至微黄色时出锅，每100kg橘红用蜂蜜18.75kg。
