# 方儿茶（棕儿茶）制法

割取儿茶钩藤的带叶小枝，入铜锅加水煮沸6-8小时，经常搅拌使叶破碎，待叶变黄色时取出枝叶，将浸出液过滤后浓缩成糖浆状，倾入木盘，待冷却凝固，切成方块状，干燥即成。
