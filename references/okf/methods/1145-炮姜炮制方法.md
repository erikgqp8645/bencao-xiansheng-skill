# 炮姜炮制方法

取生姜，砂烫至鼓起，表面棕褐色。质轻泡，断面细颗粒性，中心棕黄色，边缘棕黑色。味微辛，辣。功效为温中散寒，温经止血。用于脾胃虚寒，腹痛吐泻，吐衄崩漏，阳虚失血。
