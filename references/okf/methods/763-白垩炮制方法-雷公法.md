# 白垩炮制方法（雷公法）

炮制白垩时，勿用色青并底白者。先单捣令细，三度筛过，再入钵中研之。然后用盐汤飞过，曝干。每修事白垩二两，用白盐一分，投于斗水中，用铜器物内沸十余沸，然后用此沸水飞过白垩，以免结涩人肠。
