# 脏腑泻火药对应表

列出各脏腑对应的泻火药：黄连泻心火，木通泻小肠火，黄芩泻肺火（栀子佐之），柴胡泻肝火（黄连佐之），白芍药泻脾火，石膏泻胃火，知母泻肾火，黄柏泻膀胱火，柴胡泻三焦火（黄芩佐之）。强调各药不只能泻火，更可随证为君臣，勿执一。
