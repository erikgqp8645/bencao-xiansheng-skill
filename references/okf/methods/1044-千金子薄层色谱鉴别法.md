# 千金子薄层色谱鉴别法

取粉末2g，加石油醚80ml回流30分钟弃去，药渣加乙醇80ml回流1小时，滤液蒸干后加乙醇10ml溶解作为供试品。以秦皮乙素为对照，在硅胶G薄层板上以甲苯-醋酸乙酯-甲酸（5:4:1）展开，紫外灯365nm下检视，供试品应显相同亮蓝色荧光斑点。
