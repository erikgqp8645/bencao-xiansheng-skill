# 煎樟脑法与升炼樟脑法

煎樟脑法：樟木片浸井水三日三夜，煎汁待白霜，滤去滓，瓦盆经宿结块。升炼法：铜盆铺陈壁土与樟脑层层相间，薄荷安土上，覆盆封固，火炙，脑升于上盆。
