# 鳖甲修治要点（古籍）

取绿色九肋、重七两者为上。用六一泥固济瓶子底，待干，置甲于中。治症块及寒心用头醋三升入瓶内大火煎尽，去裙留骨，炙干用。治劳热以童便一斗二升煎尽，去裙留骨，焙干，石臼中捣成粉，以鸡䏶皮裹之，取东流水三斗，以盆盛水，阁于盆上一宿，取用，力有万倍。
