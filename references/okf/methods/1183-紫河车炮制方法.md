# 紫河车炮制方法

制紫河车：新鲜紫河车横直割开血管，用水反复漂洗干净。花椒装入布袋煎汤，去渣，将紫河车置花椒汤中煮2-3分钟，捞出沥净水，以黄酒拌匀，再置笼屉中蒸透，取出烘干。每100个紫河车用花椒4两，黄酒3斤。
