# 木香炮制方法

木香炮制方法包括：生用理气，磨汁用（《本草易读》《本草从新》等）；煨用实肠止泻（《本草易读》《本草从新》《本草求真》等）；面裹煨用（《本草从新》《本草择要纲目》等）；入理气药忌见火（《医学入门》《本草蒙筌》等）。《中国药典》记载煨木香：取未干燥的木香片，用一层草纸一层木香片间隔平铺，烘煨至挥发油渗至纸上。
