# 硝石炮制方法

取含硝土块，击碎后加水浸泡调匀，多次过滤，取滤液澄清，加热蒸去水分，取出冷却即析出硝石结晶。另有水制（加萝卜同煮）和火制（微火炒成洁白色）两种方法。
