# 黄连炙品选用规则

酒黄连引药上行，缓其寒性，善清上焦火热，用于目赤、口疮。姜黄连缓和苦寒之性，增强止呕作用，善清胃和胃止呕，用于寒热互结、湿热中阻、痞满呕吐。吴萸连使黄连寒而不滞，清气分湿热，善舒肝和胃止呕，用于肝胃不和、呕吐吞酸。
