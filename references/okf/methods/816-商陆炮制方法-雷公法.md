# 商陆炮制方法（雷公法）

取花白者根，铜刀刮去皮，薄切，东流水浸两宿，漉出架甑蒸，以黑豆叶一重商陆一重，蒸半日（从午至亥），去豆叶晒干用。无豆叶以豆代之。
