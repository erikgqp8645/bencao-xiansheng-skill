# 沉香等七种香鉴别法

以水试沉香，没者为沉香，浮者为檀，似鸡骨者为鸡骨香，似马蹄者为马蹄香，似牛头者为牛头香，枝条细实者为青桂，粗重者为笺香，七件同一树。
