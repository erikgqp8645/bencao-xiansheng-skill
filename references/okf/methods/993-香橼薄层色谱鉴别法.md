# 香橼薄层色谱鉴别法

取粉末加石油醚浸泡超声处理，与对照药材同法制备，点于硅胶G薄层板，以环己烷-醋酸乙酯展开，喷香草醛硫酸溶液加热显色，供试品与对照药材相应位置显相同颜色主斑点。
