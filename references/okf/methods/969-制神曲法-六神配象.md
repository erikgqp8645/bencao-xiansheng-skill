# 制神曲法（六神配象）

六月六日，用白面象白虎，苍耳汁象勾陈，野蓼汁象腾蛇，青蒿汁象青龙，杏仁及北方河水象玄武，赤小豆象朱雀，六味和匀踏实，庵黄，悬风处，经年用之。
