# 麻黄与桂枝的选用原则

张仲景治伤寒无汗用麻黄，有汗用桂枝。麻黄治卫实，桂枝治卫虚。寒伤营，营血内涩，不能外通于卫，卫气闭固，故无汗发热而恶寒，用麻黄。风伤卫，卫气外泄，不能内护于营，营气虚弱，津液不固，故有汗发热而恶风，用桂枝。
