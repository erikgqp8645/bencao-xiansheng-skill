# 莲子粉末显微鉴别法

莲子粉末类白色，主为淀粉粒，单粒长圆形、类圆形等，直径4-25μm；色素层细胞黄棕色或红棕色；子叶细胞呈长圆形，壁稍厚，有的作连珠状；可见螺纹和环纹导管。
