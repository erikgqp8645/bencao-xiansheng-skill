# 蛤蚧炮制方法

蛤蚧：除去竹片，截去头足及鳞（无尾者拣去不用），切成小方块。酒蛤蚧：取蛤蚧块用黄酒浸渍后微火焙干。焙干后剪取尾部供用者称为蛤蚧尾。每蛤蚧10对用黄酒半斤。
