# 苦瓠治疗目翳法

秋取小柄或小药壶卢，阴干，于紧小处锯断，内挖一小孔如眼孔大，将眼皮上下挣开，取壶定，初虽甚痛苦，然瘀肉血翳皆渐下，不伤睛也。
