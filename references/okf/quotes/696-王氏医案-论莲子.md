# 《王氏医案》论莲子

王士雄认为莲子最补胃气而镇虚逆，反胃由于胃虚气冲不纳者，以干莲子细嚼咽之胜于他药。并指出市售石莲多为伪品，味苦反能伤胃，切不可用。
