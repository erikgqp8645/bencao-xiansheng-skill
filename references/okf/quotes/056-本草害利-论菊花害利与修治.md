# 《本草害利》论菊花害利与修治

《本草害利》记载菊花苦寒非胃家所宜，真菊延龄，野菊泄人；修治以滁州菊单瓣色白味甘者为上，杭州黄白茶菊次之，其余苦菊不入药。
