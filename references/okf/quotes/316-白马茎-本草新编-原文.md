# 白马茎《本草新编》原文

专益阳道修伟，添精益髓，绝阳可兴，小阳可长，然必加入人参、白术、山茱萸、麦冬、杜仲、熟地、枸杞、柏子仁、淫羊藿、枣仁、当归、黄、白芥子、茯神、牛膝之类，同用尤灵，否则平平也。
