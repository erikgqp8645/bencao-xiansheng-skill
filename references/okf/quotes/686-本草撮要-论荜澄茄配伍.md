# 《本草撮要》论荜澄茄配伍

荜澄茄功专治膀胱冷气，得白豆蔻治噎食不纳，得高良姜治寒呃，得薄荷、荆芥治鼻塞不通，得毕拨为末擦牙治齿浮热痛，研末调敷治蜈蚣咬伤。
