# 使用与风险声明 / Use And Risk Notice

> 本本草先生 Skill 是**本草学文献整理**工具,**不是**医疗建议工具。请在阅读以下内容后再使用。

## 1. 性质声明 / What This Is

本草先生是一个**本草文献整理者**(literature curator),不是医师、不是药师、不是诊疗 AI。

它的所有回答都基于:

- `references/okf/` 下 9,406 张 evidence card(由本草图鉴 + 本草书籍 + 思源笔记蒸馏而来)
- 12 个 OKF 章节:本草概念 / 经典原文 / 案例方剂 / 修治方法 / 诊断辨证 / 禁忌边界 / 评量 / 模板 / 工作流 / 失败模式 / 转译规则 / 学习路径

## 2. 不是 / What This Is NOT

本草先生**不是**:

- 临床诊疗 AI —— 不能替代中医师诊断
- 处方推荐系统 —— 不会开方、不会推荐剂量
- 安全性审查工具 —— 不评估药物相互作用、不评估禁忌人群
- 真实临床证据库 —— 整理的是古代本草学文献,不是 RCT / 现代药理研究
- 急救或慢病管理工具 —— 不能用于任何医疗紧急情况

## 3. 引用规范 / Citation Discipline

本草先生的所有本草学结论应当**带出处**:

- `[《神农本草经》·佚名·上品·滑石条目]`
- `[本草图鉴·滑石条目]`
- `[本草先生 · 整理自 N 张 evidence card]`

如果某条说法本草先生找不到来源,会直接说"本草文献暂未发现此说法",**不编造**。

## 4. 与现代医学的差异 / Gap vs Modern Medicine

本草先生整理的材料以**古文献为主**:

- 《神农本草经》(成书约东汉)、《本草纲目》(明代)、《本草衍义》(宋代)、《本草品汇精要》(明代)、《经史证类备急本草》(宋代)等。
- 与现代中药学、药理学、临床实践有大量差异。
- 古文献中的"性味归经"是本草学传统术语,不是现代药理学分类。

任何临床用药决策,都必须:

1. 咨询有执业资格的中医师
2. 参考现代中药学教材和临床指南
3. 注意个人体质、合并症、药物相互作用

## 5. 不冒充古人 / No Impersonation

本草先生**不冒充**任何具体古人或医家说话:

- 不会写"张仲景曰..."(除非该引文在原典里有明确归属)
- 引用《本草纲目》时区分"时珍曰""禹锡曰"等不同作者的段落
- 整理归纳的内容会标注"本草先生 整理"

## 6. 隐私与数据 / Privacy

- 本 Skill 的 evidence base 来自**公开本草学经典 + 个人思源笔记**
- 个人思源笔记部分已经合并入 evidence base,**不直接暴露原文**
- `raw/` 目录(本草图鉴 + 本草书籍 + 思源笔记原文件)默认 `.gitignore`,不进 GitHub
- 蒸馏过程的 `data/text_sources/chunks.jsonl` 和 `data/course_package.json` 也已 `.gitignore`

## 7. 责任 / Liability

本草先生按"原样"提供。对使用本草先生导致的任何医疗决策、用药决策、健康决策,本 Skill 作者不承担责任。

使用本草先生 = 你接受本草先生是文献整理工具、不是医疗工具。

## 8. 反馈 / Feedback

发现本草先生的 evidence card 有错误、遗漏、来源不清?

- 检查 `references/okf/concepts/<id>-*.md` 的 `# Citations` 段
- 重新蒸馏:见 `docs/BUILD.md`
- 提交 issue / PR 到本仓库

最后,本草学是个**浩瀚的传统**,本草先生只是它的一个切面。学无止境,望本草先生助你**入门**而非**代你判断**。
